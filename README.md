# DoDo WA Sender (Android)

## بناء الـ APK بدون Android Studio (عن طريق GitHub)
1. اعمل حساب على github.com، وأنشئ Repository جديد (Private أو Public).
2. ارفع كل محتويات الفولدر ده (بما فيهم فولدر .github).
3. من تبويب **Actions** اختار **Build APK** واضغط **Run workflow**.
4. بعد 5-8 دقايق افتح العملية الخضرا ونزّل **DoDo-WA-Sender-apk** من Artifacts. جواه الملف `DoDo-WA-Sender.apk`.

## التثبيت
انقل الـ APK للموبايل، افتحه، واسمح بـ "Install unknown apps" لو طلب.

## الاستخدام
- تبويب **لوحة التحكم**: الأرقام والرسالة والملف والتأخير، ثم **ابدأ**. بيفتح تبويب **واتساب** لوحده.
- سجّل دخول واتساب: من نفس الموبايل اختار **Link with phone number** (بدل QR) وادخل الكود في تطبيق واتساب.
- سيب الشاشة شغالة والتطبيق مفتوح لحد ما الإرسال يخلص.
